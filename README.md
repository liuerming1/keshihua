# 时空史图

新会话接手先读 [项目接手说明](项目接手说明.md)：包含当前架构、清洗状态、未完成需求、流程及技术栈，与工程进度同步更新。

本机高中历史可视化项目。主页 `/` 保留任务 01—09 的虚构功能演示，不能用于正式历史学习；`/textbook` 是教材资料入口，读取清洗后的《中外历史纲要（上）》数据。两者分开，不把演示地图当成真实历史版图。

## 运行

需要 Node.js >=22.12.0 和 npm。项目目录执行：

```powershell
npm ci
npm run dev
```

访问 http://127.0.0.1:5173 。教材资料入口为 http://127.0.0.1:5173/textbook 。依赖已经安装时直接执行 `npm run dev`。开发服务仅监听本机。若端口被占用，以终端显示地址为准。教材入口读取已生成的 `public/data/history_book_01.json` 和 `public/textbook-assets/`；当前重清洗包为808条展示知识，重建使用 `scripts/finalize_reclean_textbook.py --publish`；旧重建入口会识别并保留新管线。

```powershell
npm run typecheck
npm test
npm run build
npm run preview
```

浏览器测试使用本机 Google Chrome。构建输出在 `dist/`。本次使用 Windows、Node 24.18.0、Chrome 153.0.8010.48 验证；不是手机端或跨浏览器完整认证。

## 浏览方式

1. 初始 1900—1999 全球视图，拖动旋转地球。点击聚合气泡展开知识或从右侧列表阅读。
2. 进入中国区域变为十年，进入省级示意区域变为一年。前后切换区间，或输入起始年份；返回恢复上一层原区间。
3. 切换政权／疆域与发展主题着色，并通过主题筛选知识。
4. 详情分块展示流程、要点、背景与影响，可展开多个出处；关联知识可定位至自身年代。
5. 1900 与 1910 的虚构地图状态不同；1800 为资料缺项；公元前 1 年用 `-1` 输入。没有 0 年。

只保存当前页面内导航状态，刷新重置。WebGL 不可用时仍能通过列表阅读。

## 模块分工与复用

| 模块 | 公开入口 | 责任 |
| --- | --- | --- |
| 历史知识 | `src/modules/history/index.ts` | Knowledge/Source/Relation、统一查询、时间规则、主题及演示资料 |
| 地图探索 | `src/modules/map/index.tsx` | Globe 接收标记、时点、层级、颜色、关系，报告选择和下钻 |
| 学习阅读 | `src/modules/reading/index.tsx` | ReadingPanel 接收筛选结果、详情、关联集合及资料状态，报告选择和返回 |
| 项目组合 | `src/App.tsx` | 页面内导航、主题及选中状态；将同一查询结果交给地图和列表 |
| 教材导入 | `src/modules/history/textbook.ts` | 保留多主题、未知时间、证据、图片、核验及地图层的只读 JSON 适配 |
| 教材入口 | `src/TextbookApp.tsx` | 按时间／主题浏览教材，查看证据、独立配图、地图原图及图内标签 |

地图不查询知识数据；阅读不直接导入演示数据集。所有模块通过公开输入输出组合。当前是同一网页内的模块，并未发布独立 npm 包或部署 HTTP 服务。未来答题仍是后续能力。

时间采用无零年的历史纪年，区间两端均包含；duration 表示真实年份数量。持续过程按交集筛选，未结束过程不外推到资料覆盖窗口之外。范围为测试数据范围，不是教材覆盖范围。
