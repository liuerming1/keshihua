# 03: 按时间显示单点事件与持续过程

Status: ready-for-agent

**Parent:** [中国高中历史知识可视化：首版规格](../spec.md)

**What to build:** 切换区间时，地图及基本知识入口只显示符合时间条件的事件，跨年过程和起源事件不会误归属。

**Blocked by:** [02：在百年、十年和一年视图间下钻与返回](02-region-time-navigation.md)

**外部资料条件：** 无教材前置，可用显式测试数据验证时间规则；不把测试年代解释为史实。

**执行条件：** 仅当前置任务已验收完成、外部资料条件满足时进入执行；发布标签不代表任务已开始或完成。

## Acceptance criteria

- [ ] 用有限测试集覆盖区间内外单点、开始于区间前的持续过程、完全不相交过程、思想起源与后续事件。
- [ ] 持续过程与区间相交即显示，标明起止或持续状态；起源气泡不永久出现。
- [ ] 明确区间端点、跨公元纪年和资料末端的统一处理约定，验证边界事件不因换档重复或遗漏。
- [ ] 以浏览器时间切换结果为主验证，不只检查日期函数返回值；每个显示条目可打开基本详情。

## Traceability

用户故事 20、21、22、23；父规格验收 T07、T08。

## 执行约定

- 验证使用用户已确认的浏览器公开学习路径，必要时补充公开模块接口检查；分别报告功能、数据结构与历史内容核验。
- 记录本轮变更及验证证据，实际遇到问题才建立或更新排查条目；实现细节按项目规范处理。
- 本任务不包含答题、徽章、学习记录、情景动画、手机端、线上部署或通用服务。候选模块和接口形态仍需在对应实现工作中明确，不以本次拆票替代技术决定。
- 任务 01—12 是功能与代表性内容阶段；全教材知识及地图资料须按实际清单追加批次，另做全量首版验收。
