# 06: 通过聚合气泡和列表访问密集知识

Status: ready-for-agent

**Parent:** [中国高中历史知识可视化：首版规格](../spec.md)

**What to build:** 在知识密集的区间，远处显示聚合数量，放大展开，侧边列表始终提供当前范围的全部条目。

**Blocked by:** [03：按时间显示单点事件与持续过程](03-temporal-event-selection.md)

**外部资料条件：** 无教材前置，可用测试数据验证密集场景。

**执行条件：** 仅当前置任务已验收完成、外部资料条件满足时进入执行；发布标签不代表任务已开始或完成。

## Acceptance criteria

- [ ] 采用有密集点、同位置多条知识和少量孤立点的有限测试集验证聚合与展开。
- [ ] 地图与列表使用同一时间／区域结果，聚合数量按知识条目核对，不随视觉重叠丢失条目。
- [ ] 最深层仍重叠的知识可从列表选择并打开现有详情；空结果可明确观察。
- [ ] 切换区间、缩放和选中条目时，不出现列表残留旧条目或打开其他知识的情况。

## Traceability

用户故事 16、17、18、19；父规格验收 T05、T06。
