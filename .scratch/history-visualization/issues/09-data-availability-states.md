# 09: 区分无匹配知识、缺资料和示意内容

Status: ready-for-agent

**Parent:** [中国高中历史知识可视化：首版规格](../spec.md)

**What to build:** 用户遇到空结果、资料缺失或示意空间信息时能看懂差别，并能返回有效浏览，不被误导为没有历史事件。

**Blocked by:** [04：切换年代时呈现起点版图与历史名称](04-historical-map-snapshots.md)；[05：侧边阅读完整知识与可追溯教材出处](05-knowledge-details-and-sources.md)；[06：通过聚合气泡和列表访问密集知识](06-marker-clustering-and-list.md)

**外部资料条件：** 无教材前置，用受控缺项数据验证，不创建虚构故障记录。

**执行条件：** 仅当前置任务已验收完成、外部资料条件满足时进入执行；发布标签不代表任务已开始或完成。

## Acceptance criteria

- [ ] 用正常零匹配、知识资料缺项、地图年代缺项及示意范围等有限场景验证状态。
- [ ] 示意与待补充提示跟随相关地图或详情，不用虚构精度填补缺失事实。
- [ ] 缺地图资料仍如实说明已有知识的可用性；没有依据的历史名称或疆域不继续伪装成有效资料。
- [ ] 经浏览器从缺项状态返回有数据区间，列表、详情及提示恢复一致；无需新增后台或错误管理平台。
