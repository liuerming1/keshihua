# 01: 本机打开地球并阅读一条示例知识

Status: ready-for-agent

**Parent:** [中国高中历史知识可视化：首版规格](../spec.md)

**What to build:** 本机启动网页后，能旋转地球、看到时间提示，点击一个标明用途的示例气泡，在侧边读到基本信息并返回。

**Blocked by:** None (can start immediately) — 无任务前置。

**外部资料条件：** 无教材前置，可用明确标注的测试数据。

**执行条件：** 仅当前置任务已验收完成、外部资料条件满足时进入执行；发布标签不代表任务已开始或完成。

## Acceptance criteria

- [ ] 只贯通一个默认区间、一个位置和一条示例知识；示例明确标为测试用途，不计入教材覆盖。
- [ ] 数据经公开交互进入地图和侧边阅读，不把示例文案仅硬写在按钮上；记录必要的运行方式与最小技术选择。
- [ ] 浏览器可完成打开、旋转、点击、阅读和返回，基本文字与控件可用。
- [ ] 用这条公开学习路径验证行为；当前不建立答题、成就、账号、进度保存或独立服务。
