# 07: 按发展主题切换地图颜色和知识筛选

Status: ready-for-human

**Parent:** [中国高中历史知识可视化：首版规格](../spec.md)

**What to build:** 用户可以在政权／疆域与发展主题之间切换，查看选定主题的地图颜色、图例和一致的知识列表。

**Blocked by:** [04：切换年代时呈现起点版图与历史名称](04-historical-map-snapshots.md)；[06：通过聚合气泡和列表访问密集知识](06-marker-clustering-and-list.md)

**外部资料条件：** 无教材前置；正式主题词汇及着色依据随真实资料落实。

**执行条件：** 仅当前置任务已验收完成、外部资料条件满足时进入执行；发布标签不代表任务已开始或完成。

## Acceptance criteria

- [x] 先用两个不同主题和多主题并存的代表性数据贯通切换；不增加情景动画。
- [x] 主题取整个所选区间，版图继续取起点，轮廓保持可辨，图例随模式更新。
- [x] 相同区域、时间和主题下，地图入口、聚合数量和列表一致；清除主题筛选后恢复相应全量条目。
- [x] 通过界面在主题、区间和空间层级之间切换验证，颜色不被同时解释成不同含义。
