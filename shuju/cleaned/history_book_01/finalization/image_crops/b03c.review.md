# b03c 图片裁剪框审阅（PDF 页序 95–103）

本段以原始 PDF `shuju/普通高中教科书·历史必修_中外历史纲要（上）.pdf` 为源，使用 150 dpi 逐页渲染图目视核对，并以 PDF 页面图像对象坐标复核照片、肖像和插图边界。页 95、102 未发现资产清单中的独立图片；页 96–101、103 共 11 个资产均在 `b03c.json` 中出现一次。

- `history_book_01_p0097_a001`：取英国走私鸦片飞剪船圆角照片本体，排除下方图注。
- `history_book_01_p0097_a002`：取英国东印度公司印度鸦片仓库照片本体，排除右侧图注和页脚。
- `history_book_01_p0098_a001`：取“1840年前的中国和世界形势图”的完整可见地图区域，包含椭圆地图、地名、边界线和底部图例，排除图题及下方正文。
- `history_book_01_p0098_a002`：取林则徐肖像的嵌入图像框，保留原有白底，排除姓名及生卒年图注。

- `history_book_01_p0099_a002`：取英军占领广州期间劫掠情形的黑白插图本体，保留其白底，排除图注。

## 复合图与疑点

- 页 96 的 `history_book_01_p0096_a001` 是全宽淡化背景插图，正文和页脚水印与背景叠合；当前框仅表示页面中的可见连续区域，属于复合版式资产。原始 PDF XObject image_index=0 可供后续无文字导出，不能把本页面框直接当作无字导出文件。
- 页 98 的 `history_book_01_p0098_a001` 是历史示意地图，地图主体与图例在同一资产框内；地图包含大量地名、国界及殖民地标识，但裁剪不代表已完成空间校准、历史边界核验或运行时几何数字化。
- 页 99 的 `history_book_01_p0099_a002` 为白底黑白插图，白底属于嵌入图像画面的一部分；图注未混入框内。
- 本段没有发现正文段落混入地图裁剪。页 98 地图框保留地图内部标注和图例，这是资产内容，不是页面正文；图题及地图下方正文均在框外。
- 人物肖像、签字页照片和战争场景均按 PDF 嵌入图像矩形边界裁切，未从画面风格推断身份、年代或地点。

## 自检

- 资产来源清单：`all_verified_819.json` 中按 `page_id` 筛得页序 95–103 共 11 项。
- 交付覆盖：11/11 个资产 ID 各出现一次，`unresolved` 为空；页 95、102 无目标资产，未用整页替代图片。
- 坐标检查：11 个 bbox 均为四元数组，满足 `0 ≤ x0 < x1 ≤ 1`、`0 ≤ y0 < y1 ≤ 1`，页面原点为左上角；背景图和嵌入图对象超出页面的部分已按可见页面裁到 0–1 范围。
- 视觉检查：照片、肖像和插图均未纳入图注；页 98 地图保留地图内部图例并排除图题和正文；页 96 复合背景叠印问题已列为疑点。
