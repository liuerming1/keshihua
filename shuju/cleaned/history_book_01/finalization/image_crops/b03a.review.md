## 复合图与疑点

- 页 77 `history_book_01_p0077_a001` 是全宽淡化背景插图，正文文字与背景叠合；当前框只表示 PDF 中可见连续区域，不能据此宣称获得无字原图。
- 页 79 `history_book_01_p0079_a001` 与页 81 `history_book_01_p0081_a001` 是教材历史示意地图。裁剪框保留图内图例和标注，但不代表已完成空间校准、历史边界核验或可直接生成运行时几何。
- 页 80、84 的人物画像采用 PDF 嵌入图像矩形边界；画像本体为椭圆形，矩形四周的原有白底属于嵌入图像画面的一部分，未强行按可见椭圆再次切割。
- 页 83 起居注照片中的细小文字未逐字 OCR；页 84 奏折照片中的细小文字也未逐字识读。裁剪仅定位视觉资产，不扩写图像以外的史实。

## 自检

- 资产来源清单：`all_verified_819.json` 中按 `page_id` 筛得页序 76–85 共 11 项。
- 交付覆盖：11/11 个资产 ID 各出现一次，`unresolved` 为空；页 76、82 无目标资产，未用整页替代图片。
- 坐标检查：11 个 bbox 均为四元数组，满足 `0 ≤ x0 < x1 ≤ 1`、`0 ≤ y0 < y1 ≤ 1`，页面原点为左上角。
- 视觉检查：照片/画像按嵌入图像框定位且未纳入图注；页 79、81 地图按黑色外框定位并保留图例；页 77 复合背景叠印问题已列为疑点。
- 本轮仅新增 `b03a.json` 与 `b03a.review.md`，未修改 `all_verified_819.json`、PDF 或应用代码。
