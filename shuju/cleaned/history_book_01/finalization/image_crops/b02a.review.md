## 复合图与疑点

- 页 39、44、45 的资产是“地图主体 + 图内图例/插图”的复合视觉图。裁剪框沿地图黑色外框，保留框内图例和南海诸岛插图；地图右侧或左侧的独立地名说明栏没有并入，避免把版面辅助文字当成地图图像。
- 页 42 的三项资产在同页下方并列出现：左侧曲辕犁壁画、中部唐三彩盘、右上唐太宗画像，彼此没有共用图框，分别独立定位。
- 页 43 的《职贡图》是整幅横向画面，交河故城是上方独立照片；两者均排除图题和说明文字。
- 页 40、46 为探究与拓展/史料阅读版面，未见资产清单中的独立图片，不新增裁剪项。
- 本轮没有导出独立图片文件，JSON 仅交付归一化裁剪框；地图几何、图片来源和历史事实仍按原清洗批次的待核验状态处理。

## 自检

- 资产覆盖：13/13；每个目标资产 ID 仅出现一次，`unresolved` 数量为 0。
- 坐标：13 个 bbox 均为四元数组，满足 `0 <= left < right <= 1`、`0 <= top < bottom <= 1`。
- 页序覆盖：资产仅来自 PDF 页序 39–48；页 40、46 无目标资产，未用整页替代图片。
- 复核依据：照片类框与 PDF 页面图像对象坐标一致；地图类框按渲染图中黑色外框像素边界定位。
