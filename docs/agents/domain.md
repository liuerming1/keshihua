# Domain Docs

## 布局

本项目使用 single-context：术语表为根目录 `CONTEXT.md`，架构决定记录位于根目录 `docs/adr/`。本文中的路径均相对项目根目录。

## 查阅规则

- 探索领域或代码前，若 `CONTEXT.md` 存在则先读取。
- 读取 `docs/adr/` 中与当前任务有关的决定。
- 若这些文件不存在，直接继续；不把缺少文件作为阻塞，也不为了搭目录创建空白文件。
- 领域术语和符合记录条件的架构决定由 domain-modeling 等对应工作按需建立。本次设置只写读取约定。
- 现阶段已讨论的术语和决定可按需从 `项目讨论总稿.md` 查阅，当前项目规范见 `Agent.md`。

## 术语与决定

输出需求、任务标题、设计或测试时，沿用领域文档已经定义的术语。缺少定义时先判断是否可以使用已有概念；确有缺口则在对应领域建模工作中补齐。

拟议方案若与已有 ADR 冲突，明确指出冲突和重新讨论的理由，不悄悄覆盖原决定。
