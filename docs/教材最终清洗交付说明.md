# 《中外历史纲要（上）》最终清洗与导入说明

## 可直接使用的交付

- `public/data/history_book_01.json`：当前项目可直接读取的单一 JSON 包，包含 819 条知识、894 条教材清单、2621 个原文证据块、256 个图片资产和 45 条地图栅格图层。原 `all_verified_819.json` 保留不动。
- `public/textbook-assets/`：256 张独立 PNG，约 61.57 MiB。其中 12 张叠印背景图优先从 PDF 原始 XObject 导出，其余按逐页复核的 bbox 裁切；每项记录源页、裁剪框、SHA-256、像素尺寸和导出方法。
- `src/modules/history/textbook.ts`：读取 JSON 的类型化仓库。`src/TextbookApp.tsx`：已有网页的 `/textbook` 教材入口，支持时间／主题筛选、未定年单列、原文页码、图片、核验限定和地图资料浏览。主页 `/` 的虚构演示仍独立存在。

本地运行 `npm run dev` 后访问 `http://127.0.0.1:5173/textbook`。从 PDF 和审阅框重建时运行 `python scripts/finalize_textbook.py`；此脚本使用项目 Python 运行环境中的 `pypdf`、`pdfplumber`、`Pillow` 与 Poppler。全部 24 段审阅框须齐全、覆盖页序 1–223 且无 `unresolved` 才会生成完整包。

## 事实与结构

用户提供的 `all_verified_819.json` 是事实核验输入；本轮两组子代理按原 PDF 和核验建议做修订，主代理另外复核赵州桥、南宋年代、1949 年南京条目标题及跨页史料。最终知识事实状态为 773 条 `ready`、46 条 `qualified`、0 条 `needs_source`。`qualified` 条目需在界面显示其来源归属或限定说明。旧 `review_status=pending_review` 与旧 `validation.semantic_review_status=not_performed` 是抽取阶段的原始字段，保留以便追溯；以新增 `finalization.status` 作为本次导入判断。

旧中间格式的集合、ID、原始出处和用户核验报告均保留。全书 223 页、819 知识、894 清单和所有原文指针经结构校验为 0 项错误。第 94 页《童心说》史料已链接第 95 页续文；原文仍分属两页证据块。赵州桥全球性桥型表述和南宋 1276／1279 年口径的外部依据与教材块分别标注，未把外部史料冒充教材原文。

## 地图数字化的实际边界

45 张教材地图已从 PDF 独立导出为可检索的栅格图层，并保留题名／参考年代、图例、历史地名和教材证据链接。从 PDF 文字层精确定位了 244 个图内标签的**图片内归一化位置**；20 个候选名称没有匹配到可确认的文字层位置，留作人工复核。这些图片坐标不是经纬度。

另从 UNESCO 良渚世界遗产 [原始坐标表](https://whc.unesco.org/en/list/1592/maps/)引入四个 2019 年遗产组成区参考点，记录其 DMS 原值、换算坐标和时间口径。它们不是史前良渚文化边界，也不是教材地图的地理配准结果。45 张地图均标注 `georeferenced=false`、`geometry_status=not_digitized`；未发布虚构历史边界、迁徙路线或位置气泡。可用的外部时序行政／栅格资料、年份适配和授权限制见 `docs/历史地图数字化资料核查.md`。

当前还保留 37 条阻断后续**空间／关系完善**的审阅项：25 条地图图像／几何、11 条地点／地图空间依据、1 条豪强与东汉衰亡因果探究；事实缺源项已清零，但这些尚不能当作精确空间几何已完成。320 条知识没有确定的 `time.start_year`；其中有明确上下界的记录仍可依该窗口查询，完全无法定位到时间区间的记录在界面单列，不擅自推断为“持续中”。
