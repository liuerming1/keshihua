## 结论先行

这 45 条候选不能按同一种“历史疆域 polygon”处理。它们至少分为四类：疆域或政区快照、遗址／文化分布点、路线／进军方向、战场或势力控制示意。教材图中的线、色块和箭头是图像证据，不自动成为具有经纬度和拓扑含义的矢量。

目前能确认的现成资料有：

- **可作为有年代行政几何候选、但必须逐条查源注并限制范围**：CHGIS 的政权、省、府级等时序 polygon；其数据库明确说明 polygon 主要用于府、省、王朝／政权，县及大量聚落多数只有 point。覆盖从 221 BCE 至 1911 CE，但内蒙古、青海、新疆、西藏不在当前时序范围。适合核查候选 **7、10—16、19—20、22、25、26** 的行政层，不能据此补齐教材图中的族群界、战区、影响区或路线。
- **有明确年代的已配准参考图层（WMTS 栅格，不是可直接发布的 GeoJSON）**：中研院 CCTS 列出西周、春秋、战国、秦（210 BCE）、西汉（7 BCE）、三国（262）、西晋（281）、东晋（382）、南北朝（497）、隋（612）、北宋（1111）、南宋（1208）、元（1330）、明（1582）、清（1820）及唐交通路线、明驿站与驿路等图层。它们可用于核对位置或作经纬度控制背景；CCTS 页面标明 “All rights reserved”，使用、缓存、再分发前必须取得许可。
- **可确认的遗址点／保护范围例外**：良渚古城（候选 3）有 UNESCO 世界遗产页面给出的四个组成区坐标、面积和地图，但这是 2019 年遗产属性及缓冲区，不等于教材所称“良渚古城”在新石器时代的完整聚落或文化分布 polygon。其他旧石器、新石器遗址应逐点以国家文物名录、地方文物普查或考古报告核实；不能从教材小比例地图读像素坐标。
- **路线、战役和势力控制示意**：本次没有找到可直接替代教材箭头／色块、且覆盖这些具体事件和年份的高信任现成矢量。应保留为 `route_schematic`、`point_set` 或 `area_uncertain`，由有出处的地点 point 和人工审校后的近似线／面组成；不能宣称为精确历史边界。

因此，当前建议只把 **#26（1820 行政快照）**列为“已有完整年代层、可进入 GIS 核验流程”的首选；**#7、#10—16、#19—20、#22、#25**可进入“CHGIS 行政层逐条核对”队列；其余候选先作为图像证据、点位或不确定示意，不能直接生成精确疆域。

## 45 条候选逐项核查

状态含义：

- **行政层可核验**：有 CHGIS 时序／年层或明确年代参考图层，但只承诺行政单位中实际有依据的 polygon；发布前必须查 source notes、时点和范围。
- **点位可核验**：可用官方遗址／地名／治所资料做 point；不能从点位推成面。
- **参考图层可用**：有年代化 WMTS／扫描图作为视觉核对或配准背景；不等于已有可发布 vector。
- **不可精确边界**：教材图表达路线、箭头、控制区、影响区、势力范围或有意模糊的边界；只能做示意或保留图像证据。

## 建议的数据发布规则

1. **地图候选与运行时几何分离。** `map_candidates.geometry` 继续允许 `null`；另建 `map_geometry_reviews` 或等价中间层，至少包含 `geometry_kind`（`point` / `line` / `polygon` / `raster_reference`）、`temporal_validity`、`spatial_precision`、`source_url`、`source_note`、`license`、`gcp_file`、`transform`、`rms_error` 和 `review_status`。
2. **先做点，再做面。** 都城、治所、遗址、战场和到达地可以按官方或项目所属 gazetteer 逐点核验；行政 polygon 只接受有明确年代和 source notes 的数据；路线和控制区不因地图上有线／色块就闭合为精确面。
3. **年代必须严格匹配。** 210 BCE 不得作为 221 BCE，497 不得作为 572，612 不得作为 669，1208 不得作为 1142，1582 不得作为 1433。只有在界面明确标注“邻近参考层”时才能显示。
4. **配准过程可复核。** 对教材图或外部扫描图，保存原图、GCP 点表、目标 CRS、变换类型、残差报告和人工数字化版本；没有可识别控制点时保留栅格证据，不输出假坐标。
5. **授权先于接入。** CHGIS V6 的学术／非商业限制、CCTS 的 All rights reserved、国家文物和 UNESCO 条目各有不同权利条件。项目若要随网页打包或公开再分发，必须逐层取得许可或改用明确允许再分发的来源；“网页能访问”不等于“可以下载并分发”。
6. **首批实现顺序。** 先核验 #26 的 1820 行政层和 #3 的 UNESCO 遗产组成区；其次选择一个 CCTS 年代栅格做受许可的参考层；然后再挑 #11 或 #22 做 CHGIS 行政层 point／polygon 对照。#8—9、#18、#23—24、#30—45 应作为路线／事件示意专题，不应阻塞首版行政快照。

## 后续实际落地记录（2026-09-21）

基于逐页标定的教材地图裁剪框，`scripts/digitize_map_labels.py` 从 PDF 文字层提取图内地名的图片归一化位置，输出 `finalization/map_labels.json`。这些坐标仅在裁剪图像内有效，不是经纬度；未匹配名称保留为待核验。最终导入包用 `map_layers` 索引 45 张教材栅格地图，并将已匹配标签与未匹配名称分别保存。没有地理控制点的原图继续标为 `georeferenced=false`、`geometry_status=not_digitized`。

另将 [UNESCO 良渚遗产坐标表](https://whc.unesco.org/en/list/1592/maps/)中的四个组成区公布坐标换算为 WGS84 点，保存于 `finalization/verified_map_points.json` 并进入导入包 `map_reference_points`。原表的 DMS、UNESCO 编号、来源 URL、2019 年遗产属性时间口径与“非历史边界”标识一并保留。这四个点并不表示史前良渚文化全域，也不构成教材图的配准。
