## 接入与重建

现有项目无需数据库迁移或后端服务。运行 `npm run dev`，打开终端显示的本机地址下 `/textbook`。静态部署产物位于 `dist/`，本次仅生成本机构建。

重建使用当前 Python 环境执行：

```powershell
python scripts/finalize_reclean_textbook.py --publish
```

本机 Python 不在 PATH 时，使用 `C:/Users/Administrator/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe -B -X utf8`。不带 `--publish` 只生成工作目录结果；带参数会在校验后原子替换公共 JSON，并校对旧文件身份。已发布重清洗包后，旧入口 `scripts/finalize_textbook.py` 会转到新管线，防止从旧输入覆盖本轮修正。

六段补丁是经主审更新的规范化输入；各页段内部临时生成脚本属于过程证据，不应跳过后续修订直接重跑替代最终补丁。
